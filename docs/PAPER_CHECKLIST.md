# Checklist before posting the preprint

1. Run `notebooks/L1_vs_L2_Comparison_Colab.ipynb` to completion on Colab.
2. Commit or attach `results/table5_main_comparison.csv` with the numbers you will cite.
3. State subsample sizes and epoch counts in the Experimental Setup section.
4. State whether the EIF backend was `eif` or `sklearn_iforest`.
5. Insert Table 5 into the manuscript and remove any remaining placeholders.
6. Add selected course figures (market context, PCA, t-SNE) with captions.
7. List limitations: missing manipulation labels, different L1 and L2 sampling rates, short training schedules, single time period.
8. Export PDF and submit to arXiv under `cs.LG` (optional secondary category `q-fin.ST`).
